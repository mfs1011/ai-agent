# Yo'l xaritasi

## Bajarilgan (MVP)
- Telegram bot: DM — sozlamalar/statistika, ishchi guruh — agent, kanal muhokamalari — suhbat.
- Ruxsatlar katalogi va boshqaruvi (native tugmalar).
- Moliya: ovoz/matn orqali xarajat-daromad, tuzatish, o'chirish (undo), hisobot.
- Ovoz: agy CLI orqali (limitsiz) + lug'at + LLM tuzatish + ✏️ tuzatish tugmasi.
- Kanal feedlari: har kuni web qidiruv bilan post (yangiliklar, vakansiyalar).
- O'z-o'zini rivojlantirish: takliflar → baho → bajar → PR (merge — qo'lda).
- LLM: Antigravity CLI (agy), headless, JSON protokol bilan tool'lar.

## Keyingi
- Eslatmalar va kalendar (reminders): "ertaga 10 da ... eslat".
- Second brain: havola/fayl saqlash va tabiiy tilda qidirish.
- Telegram Mini App panel (HTTPS + Caddy) — sozlamalarni vizual boshqarish.
- Moliya: kategoriya bo'yicha oylik limit va ogohlantirish, haftalik avtomatik hisobot.
- Feedlar: manbalar ro'yxati (RSS, sayt), dublikatlarni URL bo'yicha aniqlash.
- Watchdog: sayt/API health check va ogohlantirish.
- Developer agent: istalgan repo bo'yicha tahlil va PR.
- LLM chaqiruvlari statistikasi (vaqt, token) settings'da.
